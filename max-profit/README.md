# Max Profit Optimization

A Python solution to maximize building earnings within a given time limit using recursion, memoization, and dynamic programming verification.

## 1. Problem Statement

The objective is to determine the maximum possible earnings within a given time limit by constructing different types of buildings.

Each building requires a fixed construction time and generates earnings during its operational period. Buildings are constructed sequentially, and the solution identifies an optimal construction sequence that maximizes total earnings.

## 2. Building Specifications

| Building | Code | Construction Time | Earnings per Operational Time Unit |
|----------|------|------------------:|------------------------------------:|
| Theatre | T | 5 | $1,500 |
| Pub | P | 4 | $1,000 |
| Commercial Park | C | 10 | $2,000 |

## 3. Solution Approach

The solution uses **recursion with memoization** to explore feasible building sequences and identify the maximum earnings.

### Algorithm

1. Initialize the available building types with their construction times and earnings rates.
2. Check whether each building can be completed within the remaining time.
3. Calculate the earnings generated by the building after construction.
4. Recursively calculate the maximum earnings achievable with the remaining time.
5. Compare the possible earnings and retain the best result.
6. Store previously calculated results using memoization to avoid redundant computations.
7. Return the maximum earnings, building counts, and one optimal construction sequence.

### Dynamic Programming Verification

A separate bottom-up dynamic programming implementation is included to compare the calculated maximum earnings against the recursive solution.

This provides an additional consistency check across multiple time limits.

## 4. Technologies Used

- Python 3
- Recursion

- Dynamic Programming

No external Python packages are required.
