# Max Profit Problem

## 1. Project Overview

The Max Profit Problem determines the maximum earnings that can be generated by constructing different properties within a given time limit.

There are three types of properties:

| Property        | Code | Construction Time | Earnings per Time Unit |
| --------------- | ---- | ----------------: | ---------------------: |
| Theatre         | T    |           5 units |                 $1,500 |
| Pub             | P    |           4 units |                 $1,000 |
| Commercial Park | C    |          10 units |                 $2,000 |

Only one property can be constructed at a time. The objective is to determine the optimal construction sequence that maximizes total earnings within the available time.

## 2. Problem Statement

Given a total time `n`, determine:

- The maximum possible earnings.
- The number of theatres constructed.
- The number of pubs constructed.
- The number of commercial parks constructed.
- The construction sequence that produces the maximum earnings.

The solution must account for construction time and the time remaining for each completed property to generate earnings.

## 3. Assumptions

The solution uses the following assumptions:

1. Only one property can be constructed at a time.
2. Construction activities occur sequentially.
3. A property starts generating earnings immediately after its construction is completed.
4. Each completed property earns its specified rate for every remaining time unit.
5. Earnings are calculated independently for each property.
6. No additional construction, operating, or maintenance costs are included.
7. The available time must be a non-negative integer.

These assumptions define how earnings are calculated throughout the solution.

## 4. Algorithm and Approach

The solution uses **recursion with memoization** to identify the construction sequence that maximizes earnings.

### Step 1: Evaluate the available time

The algorithm receives the total available time `n`.

### Step 2: Evaluate each property

For each property, it checks whether the remaining time is sufficient to complete construction.

### Step 3: Calculate earnings

After construction, the remaining time is multiplied by the property's earnings rate.

**Formula:**

`Property Earnings = Remaining Time × Earnings per Time Unit`

### Step 4: Evaluate subsequent construction

The algorithm recursively evaluates the remaining time to determine whether constructing another property would increase total earnings.

### Step 5: Select the optimal sequence

The algorithm compares the possible construction choices and selects the sequence with the highest total earnings.

Memoization stores previously calculated results to avoid repeatedly solving the same subproblems.

### Step 6: Verify the result

A separate bottom-up dynamic programming implementation calculates the maximum earnings independently. The result can be compared with the recursive solution.

An additional function recalculates earnings from the selected construction sequence to check its consistency.

## 10. Complexity Analysis

Let `n` represent the available time.

### Time Complexity

The recursive solution uses memoization and evaluates each reachable remaining-time state. For each state, it considers three property types.

The time complexity is **O(n)** for the current implementation.

### Space Complexity

The memoization cache stores results for reachable time states, and recursion uses additional stack space.

The overall space complexity is **O(n)**.

The bottom-up verification implementation also uses O(n) time and O(n) space.

## 11. Limitations

- Earnings rates are fixed in the current implementation.
- Construction times are fixed.
- The model assumes immediate earnings after construction.
- Additional operational costs and external constraints are not considered.
- The solution optimizes earnings only under the stated assumptions.
